# Journal de veille

Ce journal sera alimenté avec des notes datées.

## Exemple de format d'entrée

### 2026-03-16 — Sujet

- **Source** : lien vers article / vidéo / doc officielle.
- **Idée clé** : résumé en 2–3 lignes.
- **Impact potentiel** : ce que cela change pour mes projets.
- **Action** : test à réaliser / décision à prendre.
