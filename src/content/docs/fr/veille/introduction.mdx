# Veille technologique

## Pourquoi cette veille

La veille me permet de :

- rester à jour sur les évolutions de l'écosystème,
- améliorer mes choix techniques,
- identifier des opportunités d'optimisation dans mes projets.

## Axes suivis

- **Front-end moderne** : frameworks, rendu, outillage.
- **Qualité logicielle** : tests, linting, revues, standards.
- **Performance web** : métriques, optimisation, accessibilité.
- **Pratiques produit** : documentation, UX, priorisation.

## Méthode

1. Collecte des sources fiables.
2. Tri par pertinence.
3. Synthèse actionnable.
4. Expérimentation pratique.
