# Ressources

## Sources de référence

- Documentations officielles (frameworks, runtimes, standards web).
- Blogs techniques d'équipes produit.
- Newsletters spécialisées.
- Talks et conférences.

## Outils utilisés

| Outil | Rôle |
| --- | --- |
| Agrégateur RSS | Centraliser les sources |
| Notes Markdown | Capturer les idées rapidement |
| Git | Historiser les changements |
| Tableau de priorisation | Organiser les sujets à creuser |

## Critères de sélection

- Fiabilité de la source.
- Date de publication.
- Applicabilité pratique.
- Cohérence avec mes besoins projets.
