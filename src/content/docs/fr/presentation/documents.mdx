## Espace d'upload (workflow)

Dépose tes fichiers dans le dossier suivant du projet :

`/public/documents/uploads/`

Ensuite, ils seront disponibles directement via URL, par exemple :

- `/documents/uploads/cv-vspirine.pdf`
- `/documents/uploads/rapport-veille.pdf`

<CardGrid>
  <Card title="Formats recommandés" icon="document">
    PDF pour les documents officiels, ZIP pour archives, CSV/MD pour ressources techniques.
  </Card>
  <Card title="Convention de noms" icon="seti:folder">
    Utilise des noms explicites en minuscules, ex: `rapport-veille-2026.pdf`.
  </Card>
</CardGrid>
