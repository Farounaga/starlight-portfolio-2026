# Parcours

## Frise synthétique

- **Étape 1** — Découverte du développement et des fondamentaux web.
- **Étape 2** — Premiers projets réels (front-end, APIs, déploiement).
- **Étape 3** — Structuration de la pratique : qualité, tests, documentation.
- **Étape 4** — Approfondissement : architecture, performance, accessibilité.

## Approche de progression

Je fonctionne en cycles courts :

1. apprendre un concept,
2. le tester sur un mini-projet,
3. documenter les résultats,
4. intégrer les bonnes pratiques dans mes projets suivants.

## Focus actuel

- Consolider les bases de l'architecture front moderne.
- Mieux formaliser les décisions techniques (ADR, trade-offs).
- Maintenir un rythme régulier de veille et de publication.
